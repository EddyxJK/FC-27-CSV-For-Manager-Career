FC27 MANAGER CAREER CSV
Guía de uso y agradecimientos
========================================

USO DEL PAQUETE PORTABLE

1. Descarga el ZIP portable desde la sección Releases.
2. Extrae el ZIP completo en una carpeta normal.
3. Abre FC27 Carrera CSV.exe dentro de la carpeta extraída.
4. Selecciona el guardado de Carrera de mánager que comienza con CmMgrC.
5. El programa crea un archivo terminado en _jugadores.csv junto al guardado. Puedes abrirlo con Excel u otra hoja de cálculo.

La primera vez, la aplicación localiza FC27 y prepara sus nombres desde los archivos instalados del juego. Este paso puede tardar un poco y solo se hace una vez. Necesitas tener FC27 instalado; Node.js y Python no son necesarios para usar el paquete portable. Si la aplicación no encuentra el juego, te pedirá seleccionar su carpeta.

Extrae y conserva todos los archivos del ZIP juntos: el lanzador necesita las carpetas parser y runtime. El paquete no incluye las tablas de nombres de EA. El guardado se abre solo para lectura; el procesamiento ocurre localmente y no se envían el guardado ni el CSV a ningún servicio.

COMPILAR DESDE EL CÓDIGO FUENTE

Para compilar desde el repositorio se necesita Node.js 24 o posterior, Python 3 y conexión a Internet para instalar eafc-db-kit. En PowerShell, dentro de la carpeta del proyecto, ejecuta:

    .\build-windows.ps1

El archivo portable se crea en dist\FC27-Carrera-CSV-portable-v1.0.0.zip. Para GitHub Releases adjunta el ZIP completo. No publiques el ejecutable autocontenido antiguo: Microsoft Defender lo detectó como Trojan:Win32/Wacatac.B!ml.
