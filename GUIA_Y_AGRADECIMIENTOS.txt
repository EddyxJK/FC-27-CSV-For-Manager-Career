FC27 MANAGER CAREER CSV
Guía de uso y agradecimientos
========================================

USO DEL EJECUTABLE

1. Descarga FC27 Carrera CSV.exe desde Releases y ábrelo.
2. Selecciona el guardado de Carrera de mánager que comienza con CmMgrC.
3. La primera vez, la aplicación localiza FC27 y prepara las tablas de nombres desde los archivos instalados del juego. Este paso puede tardar un poco y solo se hace una vez.
4. El programa crea un archivo terminado en _jugadores.csv junto al guardado. Puedes abrirlo con Excel u otra hoja de cálculo.

El ejecutable incluye Node y Python portátiles; no necesitas instalarlos ni usar PowerShell. FC27 debe estar instalado para poder preparar los nombres. Si el juego no está en una ruta habitual, la aplicación te pedirá seleccionar la carpeta de instalación.

El guardado original se abre solo para lectura. El procesamiento ocurre localmente y no se envían el guardado, los nombres extraídos ni el CSV a ningún servicio. Las tablas extraídas se guardan en %LOCALAPPDATA%\FC27 Carrera CSV para reutilizarlas en exportaciones futuras.

COMPILAR DESDE EL CÓDIGO FUENTE

Para compilar desde el repositorio se necesita Node.js 24 o posterior, Python 3 y conexión a Internet para instalar eafc-db-kit. Desde PowerShell en la carpeta del proyecto, ejecuta:

    .\build-windows.ps1

Esto crea dist\FC27 Carrera CSV.exe. La compilación no contiene datos de EA; la aplicación los extrae del FC27 instalado al primer uso.
